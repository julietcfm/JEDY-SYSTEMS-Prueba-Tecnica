# JEDY SYSTEMS - Prueba Técnica

Aplicación desarrollada en Python y SQL Server como prueba técnica.

## Tecnologías
- Python
- Tkinter
- SQL Server
- pyodbc

## Arquitectura
- UI: Interfaz gráfica
- BL: Lógica de negocio
- DTO: Transferencia de datos
- DAC: Acceso a datos

## Funcionalidad
La aplicación permite:
1. Ingresar un dato.
2. Guardarlo en SQL Server.
3. Consultar el dato almacenado.

## Base de datos
Base de datos utilizada: `PruebaEquipo`

Tabla: `Datos`
